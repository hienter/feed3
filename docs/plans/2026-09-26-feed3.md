**Tech Stack:** Swift 6, SwiftUI, SwiftData, CloudKit, Swift Charts, XCTest.

### Task 2: 데이터 모델 (TDD)

**Files:** `Feed3/Models/Baby.swift`, `Feed3/Models/Feeding.swift`, `Feed3Tests/FeedingTests.swift`

```swift
enum FeedType: String, Codable, CaseIterable {
    case breastLeft, breastRight, formula, pumpLeft, pumpRight
    var isBreast: Bool { self == .breastLeft || self == .breastRight }
    var isPump: Bool { self == .pumpLeft || self == .pumpRight }
}

@Model final class Feeding {
    @Attribute(.unique) var id: UUID
    var type: FeedType          // String 원시값 저장
    var startedAt: Date
    var endedAt: Date?
    var amountML: Int?
    var note: String?
    var baby: Baby?
    // 지속시간(초), 진행중 판정 계산 프로퍼티
}
```

- 테스트: 지속시간 계산, 진행중(endedAt nil), 좌우 합산 판정
- Commit: `feat: feeding model`

### Task 3: 집계 순수 로직 (TDD)

**Files:** `Feed3/Stats/FeedingStats.swift`, `Feed3Tests/FeedingStatsTests.swift`

- 입력 `[Feeding]` 배열 → 출력 구조체. SwiftUI 미의존 순수함수:
  - `dailySummary(_:[Feeding], day: Date) -> (count, totalML, breastMinutes, formulaML)`
  - `weeklySeries(_:weeks:) -> [(day, count, ml)]`
  - `hourHistogram(_:) -> [Int: Int]` (0-23시 분포)
  - `lastFeedingGap(_:[Feeding], now:) -> TimeInterval?` (마지막 종료~now)
- 테스트: 경계(자정 걸침, 진행중 제외, ml 없는 모유), 빈 배열
- Commit: `feat: stats aggregation`

### Task 4: HomeView + 기록 플로우

**Files:** `Feed3/Views/HomeView.swift`, `Feed3/Views/TimerSheet.swift`, `Feed3/Views/FormulaSheet.swift`
